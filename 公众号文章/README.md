# 知令公众号文章库

每篇文章**独立一个文件夹**，正文、配图、素材、计划书同置一处，整个文件夹可直接打包发布或归档。

## 目录约定

```
<文章短名>/
├── <文章短名>-公众号文章.md   # 正文，可直接粘贴到公众号编辑器
├── images/                    # 配图：.png 用于发布，.svg 为可再生成的源文件
├── refs/                      # 参考资料（可选）
├── 实测素材.md                 # 实测数据与事实清单（可选）
└── <文章短名>.plan.md          # 选题与制作计划（可选）
```

- 正文图片统一使用相对路径 `images/xxx.png`，文件夹移动后引用不失效。
- 未插入正文的 `.png` 为备选素材，`.svg` 均为可改数的源文件，请勿删除。
- `_archive/` 仅存旧目录结构的整体打包，用于回溯，不再更新。

## 维护提示

- 新增文章：建 `<文章短名}/` 文件夹，正文命名 `<文章短名>-公众号文章.md`，配图放 `images/`。
- 文中的价格、跑分、模型能力等硬信息，发布前按当期数据库与官方公示复核；带时效的促销（如 Argon 11-30 到期、Carbon 限时五折）过期后需同步改稿。
- 信息图统一「SVG 精绘 → 2 倍 PNG 导出」，改数只改 SVG，再重新导出 PNG。
