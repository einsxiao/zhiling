# 知令合伙人计划 · 校园海报 —— 使用说明

本目录是「知令合伙人计划」面向校园传播的竖屏电子版 + A3 打印版海报交付物。
海报为**单文件自包含 HTML**（内联 CSS / 内联 SVG logo、字标、二维码，不引用任何外部文件或网络资源），
可同时用于 1080×1920 电子屏传播与 A3（297×420mm）竖版打印。

当前版本为 **v5 定稿**：全浅色高级极简风（白底 + 超大字号 + 大色块 + 大留白）。
自上而下：品牌行（**知令应用图标 + 「知令」字标，字标着色统一到页面主色 `--blue`**）→ 主视觉 200rem「Token 自由」+ 左侧品牌蓝渐变竖条
→ 浅蓝底双大数字带（20% / 20 年）→ 底部两栏（左：**纵向三步时间线**；右：**网址锁排 + 二维码**）→ 页脚合规小字。

**v5 相对 v4 的变化（仅字标配色一处）**：品牌行字标由官方字标原色 `#1596FF`（亮青蓝，与页面主色不同族）
改为页面主色令牌 `--blue`（`#545BFC`）——与眉标、数字、步骤节点、取景角标、网址前缀同色，
由 CSS 规则 `.brand .wordmark g{fill:var(--blue)}` 单点驱动（内联 `fill` 同步为同值作兜底），此后改 `--blue` 即可整体联动。
版式、尺寸、间距与文案**均未改动**，二维码内容不变。

**v4 相对 v3 的版式变化（现行版式仍沿用）**：中间「三步加入 + 二维码」区块**左右各内缩 34rem**（带来左右留白），
区块上下间距加大（数字带↔两栏 40→60rem；两栏↔页脚实测 115rem，v3 仅 28rem），
三步节点间距由 225rem **收紧到 203rem**，二维码白卡 388→348rem（码图 344→308rem），
**页脚小字改为「贴底靠右」**（`margin-top:auto` 吸收剩余纵向空间后沉底 + `text-align:right`）。
整体节奏由 v3 的「上紧下满」改为 **「宽（数字带）—窄（两栏）—宽（页脚留白）」分层 + 底部大留白**，页面更疏朗、层次更清楚。

## 二、如何修改文案

1. 直接编辑 `知令合伙人计划-校园海报.html`，正文在 `<body>` 内的 `.content` 中，自上而下按下列注释定位：
   `A 品牌行` / `B 主视觉区` / `C 数字带` / `D 底部两栏（左：纵向三步；右：网址 + 二维码）` / `E 页脚`。
2. 常用可改项与对应选择器：

   | 想改什么 | 选择器 | 说明 |
   | --- | --- | --- |
   | 品牌行 logo（应用图标） | `.brand .logo` | 内联 SVG，`#3780ff` 蓝圆；62×62rem（官方应用图标固有色，未改） |
   | 品牌行字标（「知令」） | `.brand .wordmark` + `.brand .wordmark g{fill:var(--blue)}` | 107×42rem；**v5 起着色＝页面主色 `--blue`（`#545BFC`）**，改 `--blue` 即联动字标；内联 `fill="#545BFC"` 仅作「SVG 单独取出」时的兜底 |
   | 眉标「知令合伙人计划」 | `.eyebrow` | 前面 44×5rem 蓝色短线由 `.eyebrow::before` 生成 |
   | 主标题第 1 行「Token」 | `.title .t1` | 200rem 近黑实色 |
   | 主标题第 2 行「自由」 | `.title .t2` | 200rem 品牌蓝渐变字（`background-clip:text`） |
   | 主视觉左侧竖条 | `.hero::before` | 12rem 宽渐变竖条；`.hero{padding-left:34rem}` 为标题让位 |
   | 数字带两组数字 | `.band .num`（数字）+ `.band .num .u`（`%`/`年` 单位符） | 数字 132rem / 单位 68rem |
   | 数字带标签与说明 | `.band .lab` / `.band .desc` | 两列各一组 |
   | 数字带底部合规脚注 | `.band .foot` | **勿删**（「以平台结算为准」就近声明） |
   | 三步小标题「三步加入」 | `.kicker`（+ `.kicker::before` 短横线） | 纵向时间线所在左栏的分组标签 |
   | 纵向三步 | `.steps .step .n`（01/02/03 圆环节点）+ `.step .s`（短句） | 时间线竖线由 `.steps::before` 生成；节点由 `justify-content:space-between` 等距铺满栏高（栏高由右栏决定） |
   | 底部两栏的宽度与侧边留白 | `.duo` | `grid-template-columns:1fr 348rem; gap:64rem; padding:0 34rem`（左右各内缩 34rem；改内缩量即改左右留白） |
   | 底部两栏的上下间距 | `.duo` 的 `margin-top` | 现为 60rem（与上方数字带的间距） |
   | 行动区网址 | `.url .scheme`（`https://`）+ `.url .host`（`zhiling.plus`） | 26rem 蓝 + 54rem 近黑 900；下加 `.url .rule` 渐变短线 |
   | 二维码卡片尺寸 | `.qrcard` / `.qrcard svg`（+ `.corner` 四角） | 白卡 348rem、码图 308rem、内边距 20rem；改尺寸后需确认 `.qcap` 不折行 |
   | 二维码说明 | `.qcap` | 二维码卡片下方一行（28rem，`nowrap`，实测单行宽 311rem < 348rem） |
   | 页脚位置与对齐 | `.footer`（`.footer p` 三行 / `.sign` 落款） | `margin-top:auto`**贴底** + `text-align:right`**靠右**；**勿删**（含「年满 18 周岁」） |

3. 改完文案后**重新导出**（见第四节）。
4. 注意：改文案后建议保持原有层级字号；数字带两列文案若加长，需复查是否会折行（每列内容宽约 397rem）。
5. **数字带列数调整**：如需恢复「¥100 提现门槛」等信息，建议参照 `_archive/variants/变体3-竖条.html` 的三列写法
   （`.band .cols{grid-template-columns:repeat(3,1fr)}`，数字字号相应调回 118rem / 单位 64rem），
   并重新实测不溢出（见第五节）。

## 三、如何更换二维码

**方式一（推荐，可复现）**：改 `_scripts/gen_qr.mjs` 里的 `TEXT` 常量，然后：

```powershell
# cwd 任意；NODE_PATH 指向已安装 qrcode 的依赖目录（主项目 front_ui）
$env:NODE_PATH="D:/work/zhiling/front_ui/node_modules"
node "D:/work/zhilingdoc/知令合伙人计划-校园海报/_scripts/gen_qr.mjs"
```

脚本会输出 `_scripts/qr-partner.svg`（矢量）与 `二维码-qr-partner.png`（768px 备用）。
把 `qr-partner.svg` 的 `<svg>…</svg>` 整段替换 HTML 中 `.qrcard` 内的那个 `<svg>` 即可。

**方式二（手动）**：用任意二维码工具生成 **白底黑码、静区（quiet zone）不少于 4 个模块** 的 SVG，
替换 `.qrcard` 内的 `<svg>`；说明文字在 `.qcap`。

> 合规：**严禁在二维码上叠加任何文字或图形**，四周需保留充足留白。
> 当前二维码码图 344rem，外层 388rem 白色卡片（内边距 22rem），四角蓝色 L 形取景角标位于卡片外沿
> （`.corner`，`-14rem`），**不覆盖码面**。若改用更密的码，请复查角标与静区仍无交集。

## 四、如何重新导出

前置：Windows + Google Chrome（默认 `C:\Program Files\Google\Chrome\Application\chrome.exe`）。

```powershell
pwsh -File "D:\work\zhilingdoc\知令合伙人计划-校园海报\_scripts\export_poster.ps1"
```

脚本会依次导出 1x PNG、2x PNG、A3 PDF，并写回本目录。

如需手工执行，等效命令为（关键点见下方"注意"）：

```powershell
$chrome = "C:\Program Files\Google\Chrome\Application\chrome.exe"
$dir = "D:\work\zhilingdoc\知令合伙人计划-校园海报"

# 1x PNG
& $chrome --headless=new --user-data-dir="$env:TEMP\zlprof1" --disable-gpu --hide-scrollbars `
  --default-background-color=00000000 --force-device-scale-factor=1 --window-size=1080,1920 `
  --screenshot="$dir\知令合伙人计划-校园海报-1080x1920.png" "file:///D:/work/zhilingdoc/知令合伙人计划-校园海报/知令合伙人计划-校园海报.html"

# 2x PNG（改 --force-device-scale-factor=2）
# A3 PDF
& $chrome --headless=new --user-data-dir="$env:TEMP\zlprof3" --disable-gpu --no-pdf-header-footer `
  --print-to-pdf="$dir\知令合伙人计划-校园海报-A3.pdf" "file:///D:/work/zhilingdoc/知令合伙人计划-校园海报/知令合伙人计划-校园海报.html"
```

**注意（本机 Chrome 155 实测）**：
- 必须加 `--user-data-dir=<独立临时档案目录>`，否则命令行会被转发到正在运行的 Chrome、导致静默不产出文件；
- `--default-background-color` 必须给十六进制/RGBA（如 `00000000`）；写成 `0` 会被拒绝并导致截图失败。
- 导出脚本已先把 HTML 复制到 ASCII 临时目录再渲染（规避中文路径偶发问题），最后把产物拷回本目录。

**校验**：`python -c "from PIL import Image;print(Image.open(r'...1080x1920.png').size)"` 应为 `(1080, 1920)`；
PDF 可用 pypdf/PyMuPDF 检查页数与纸张（应为 1 页、297×420mm）。

**溢出校验（改版式后建议做）**：注意 `.poster` 有 `overflow:hidden`，此时 `scrollHeight` 恒等于画布高度、
**不能反映溢出**。正确做法是比较「最后一个区块的底边」与「画布高 1920 − 下内边距」：
前者必须 < 后者，差值为底部余量。可直接复用 `_draft/measure.mjs`（会把 `html{font-size}` 覆写为
`1px` 后在无头 Chrome 里量版式，输出各区块 top/bottom、溢出量、**横向内缩量与页脚贴底量**）：

```powershell
node "D:\work\zhilingdoc\知令合伙人计划-校园海报\_draft\measure.mjs" "D:\work\zhilingdoc\知令合伙人计划-校园海报\知令合伙人计划-校园海报.html"
```

> 量测脚本两个坑（v4 已修）：① 无头 Chrome 的 `--dump-dom` 视口比 `--window-size` 少 24px，
> 用 1080 宽会**把海报挤窄 24rem**导致横向读数失真 —— 故脚本改用 `--window-size=1400,2000`；
> ② 横向读数一律换算成**相对画布左缘**的坐标（`canvasContentX` / `duoInnerX` / `*Inset`），避免视口居中带来的偏移。

（v4 定稿实测：内容底线 1852 = 允许值 1852（页脚被 `margin-top:auto` 顶到边缘），
两栏↔页脚自动余量 115rem、页脚距画布底 68rem；三步节点间距 203rem、节点净间距 139rem；
两栏内容左右内缩各 34rem，两栏内容左/右缘距画布边缘各 126rem；二维码卡 348rem、码图 308rem。）

## 五、设计规格摘要（v5 定稿）

- **画布**：设计基准 1080×1920（9:16）；白底，大留白。
- **配色**：主色 `#545BFC`；强调渐变 `linear-gradient(135deg,#545BFC,#7C6FF7)`；
  品牌行：应用图标蓝 `#3780ff`（官方固有色，未改）、**字标 `#545BFC`（v5 起并入页面主色 `--blue`，原为官方字标色 `#1596FF`）**；
  文字主色 `#0E1024`；弱化色 `#626A80`（正文）/ `#656C82`（小字）；
  浅蓝数字带底 `linear-gradient(160deg,#F4F5FF,#EDEFFF)`，描边 `#E4E6F8`，分隔线 `#D8DCF2`。
  > 弱化色已为满足 WCAG AA（≥4.5:1）而压深，弱化层级靠字号与字重区分，请勿直接改回浅灰。
- **字级层级**：主标题 200rem（行高 .94）/ 数字带数字 132rem（单位符 68rem，基线对齐）/
  网址主域名 54rem（`https://` 26rem）/ 眉标 30rem（字距 .18em）/ 标签 28rem /
  三步短句 29rem / 扫码说明 30rem / 说明 21rem / 合规小字 19rem。
- **区块节奏（自上而下）**：品牌行 → 主视觉 → 数字带 → 底部两栏（左：纵向三步 / 右：网址 + 二维码）→ 页脚；
  实测区块间距 `30 / 52 / 60 / auto rem`（v4 起页脚为 `margin-top:auto`，自动吸收剩余纵向空间后沉底 →
  两栏↔页脚实测 **115rem**，是画面上最大的一处留白）。
  画布内边距 v4 起为 `92 / 92 / 68 rem`（下内边距由 76 收到 68，使页脚更贴底）。
  布局由 `.content` 的 `flex-start` + 各 section `margin-top` 控制；改任何区块高度后须重测不溢出。
- **底部两栏（v4 收窄内缩）**：`grid-template-columns:1fr 348rem; gap:64rem; align-items:stretch; padding:0 34rem`。
  · 左栏＝`.kicker`「三步加入」+ `.steps` 纵向时间线（`.steps::before` 竖直细线，节点 64rem 圆环，
  由 `justify-content:space-between` 等距铺满栏高；栏高由右栏决定 → v4 实测节点间距 203rem、节点净间距 139rem）；
  · 右栏＝`.action`：`.url` 网址锁排（`https://` 蓝 26rem + `zhiling.plus` 近黑 54rem + 渐变短线）+ 二维码卡片 + 扫码说明。
  · **水平留白**：两栏内容左缘距画布左缘 126rem、右缘距画布右缘 126rem（左右对称），并与主视觉眉标左缘对齐。
- **页脚**：`margin-top:auto` + `text-align:right`（**贴底靠右**）；三行合规小字 + 落款右对齐，距画布底 68rem。
- **装饰**（仅两处，浅淡几何，总覆盖率 <10%）：右上角淡蓝大圆 + 同心外环（`.deco .circle` / `.ring`，出血出画）、
  左下角淡蓝圆角方（`.deco .square`，v4 由 300rem/5% 放大到 **340rem/6%**，用于平衡「页脚靠右」后偏空的下半部）；
  另有主视觉左侧 12rem 品牌蓝渐变竖条（`.hero::before`）。
- **二维码**：SVG 盒 308rem（内含 4 模块静区，**实测码图符号 239rem**）、白卡 348rem（v4 由 344/388 收小，为左右与上下腾出空间），
  四角蓝色取景角标（44rem，外扩 14rem，不压码面）。
- **双画布自适应**：`html{font-size:min(0.0925926vw,0.0520833vh)}`，全篇以 `rem` 排版（1080×1920 视口下 1rem=1px），
  同一份 HTML 在 A3 竖版下按高度贴合、左右自动留白居中；打印规则：`@page{size:A3 portrait;margin:0}`，
  并以 `-webkit-print-color-adjust:exact` 保证底色与渐变正确输出。
- **深色主题不适用**：海报为独立印刷物料，固定浅色底，不套用应用 light/dark 主题。
