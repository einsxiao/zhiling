# 公司及团队介绍

## 一、公司介绍

西安禾成讴沃信息科技有限公司（以下简称"公司"）成立于陕西省西安市，是一家专注于人工智能应用与智能工作平台研发的科技企业，系"知令（ZHILING）"品牌持有者。公司以"让智能触手可及"为核心理念，致力于打造桌面与移动全场景智能工作平台，让 AI 智能体真正服务于科研、工程与日常办公的每一个环节。

公司自主研发的核心产品知令（ZHILING）是一款面向科研与工程场景的全流程智能工作台，支持 Windows、macOS、Linux 桌面端与 Android、iOS 移动端多端无缝协同。产品深度整合 DeepSeek、GLM、Kimi、MiMo 等国产大模型，通过 Prompt 工程、工具链编排与上下文管理等全链路优化，为用户提供多模型会话、复杂任务规划、自动化任务编排、文档协作、远程集群计算对接等核心能力，覆盖代码开发、文档精修、数据分析、科学计算、演示制作等全链路工作流。

在技术方向上，公司深耕 AI 智能体、大模型应用、高性能计算与自动化任务编排四大领域，具备从大模型本地化部署与推理优化，到计算集群建设、多端应用开发的完整技术能力。公司自主研发了多端三层按需同步协议、自动化任务引擎（支持定时与条件触发、计划书驱动的全流程自动编排）、本地优先的安全架构等关键技术，敏感数据可完全保留在用户环境内部，充分满足企业对数据安全与合规管理的要求。

目前，公司产品与服务已应用于高校实验室、企业研发中心与科研工作者群体，为各类机构提供高效、可靠、安全的智能工作解决方案。面向企业级市场，公司将持续深化大模型应用与智能工作平台的研发，助力大型企业客户实现办公与业务的智能化转型。

## 二、团队介绍

公司团队是一支由人工智能应用、高性能计算、全栈软件开发等方向人员组成的复合型技术团队，核心能力覆盖大模型应用与部署、计算集群建设、全栈研发与 AI 智能体开发四大领域。

**（一）大模型应用与部署能力**

团队长期从事国产开源大模型的本地化部署与应用开发，熟悉 DeepSeek、GLM、Qwen 等主流国产开源大模型的部署流程、推理优化与运维管理，在大模型推理加速、显存优化、服务化封装等方面积累了丰富的工程经验，能够根据企业硬件环境与业务场景完成模型选型、适配与调优，保障模型服务的稳定运行。

**（二）高性能计算集群建设经验**

团队曾为多所高校与科研机构建设高性能计算集群，具备完整的设计、实施与交付能力，典型项目包括：

- 为西北地区某材料计算课题组建设 20+ 节点规模的 SLURM 集群，支撑 VASP、LAMMPS 等第一性原理与分子动力学计算任务，负责集群架构设计、调度系统配置与计算环境部署；
- 为中部地区某高校物理学院建设 GPU 计算集群，服务于深度学习与分子动力学模拟等科研计算需求，完成 GPU 资源调度、作业排队与运行监控体系的搭建；
- 为西南地区某高校化工学院部署 CPU+GPU 混合架构计算平台，兼顾通用计算与 AI 加速两类场景，实现异构计算资源的统一调度与管理。

在上述项目实践中，团队积累了 InfiniBand 高速网络组网、Lustre/GPFS 并行文件系统部署、SLURM/PBS 集群调度系统配置等关键工程能力，熟悉高性能计算集群从硬件选型、系统部署到运行维护的全生命周期管理，可为本次项目的大模型算力平台建设提供直接的技术支撑。

**（三）全栈软件研发能力**

团队具备桌面端、移动端与服务端的全栈研发能力：桌面端基于 Electron + React 架构，移动端基于 React Native 技术栈，服务端采用 Django 框架，并使用 Go 语言开发高性能工具与基础设施组件，具备从产品设计、开发实现到打包发布、部署运维的完整交付能力。

**（四）AI 智能体研发能力**

团队在 AI 智能体领域拥有深厚的技术积累，自主研发了多模型调度、工具链编排、Prompt 工程与上下文管理等核心技术，产品支持多模型会话、流式推理、工具调用、子会话自治与多智能体协同，能够将大模型能力与具体业务工具深度结合，实现复杂任务的自动化规划与执行，并将相关能力沉淀为企业级应用奠定基础。

## 三、核心优势

**（一）"软件+模型+硬件"一体化交付能力**

公司同时具备大模型部署、计算集群建设与智能工作台软件开发能力，能够为客户提供从硬件方案设计、模型部署到应用软件落地的整体解决方案，有效降低多供应商协作带来的集成风险与沟通成本。

**（二）国产大模型深度适配经验**

公司核心产品深度适配 DeepSeek、GLM、Qwen 等国产大模型，积累了丰富的模型本地化部署、推理优化与业务集成经验，与本次项目"开源大模型本地化部署"的技术路线高度契合，可显著缩短部署实施周期、降低技术风险。

**（三）计算集群建设与 AI 应用双重技术积累**

团队兼具高校计算集群建设经验与 AI 应用产品研发经验，既熟悉底层算力基础设施的规划与建设，又擅长上层智能应用的开发与落地，能够从业务需求出发设计算力方案，并将算力能力切实转化为业务价值。

**（四）全链路技术覆盖**

从并行文件系统、集群调度等底层基础设施，到大模型推理引擎、AI 智能体等中间层能力，再到桌面端、移动端应用等上层产品，公司具备全链路的技术覆盖能力，能够为企业智能化建设提供端到端的技术支撑与长期服务保障。
