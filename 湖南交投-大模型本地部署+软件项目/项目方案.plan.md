# 湖南交投 - 大模型本地部署与智能工作台 项目方案

## 约束

- 客户：湖南交通投资集团有限公司
- 预算目标：200万+
- 交付形式：完整项目方案文档（Markdown/HTML）
- 时间：一周以上（从容准备）
- 核心需求：
  - 采购硬件服务器 + 部署开源大模型（DeepSeek/GLM等）
  - 知令企业版（多用户管理、权限控制、审计日志等）
  - 团队有高校计算集群建设经验（无现成文档，需整理）
- 已知资源：
  - 知令项目完整代码（D:/work/zhiling/）
  - 知令公司介绍页面（https://zhiling.plus/company/）
  - 知令产品文档（intro.md, README.md）
  - 团队有计算集群和大模型部署经验（需从零整理）

## 背景与目标

湖南交投集团期望引入大模型技术提升内部办公与业务智能化水平。考虑数据安全与合规要求，采用本地化部署方案，将开源大模型部署在自有硬件上，并基于知令（ZHILING）平台构建企业级智能工作台。

本项目目标是提供一份完整的项目方案文档，供客户评估与决策，涵盖：
1. 企业及团队介绍
2. 大模型本地部署技术方案
3. 知令企业版智能工作台方案
4. 项目实施计划
5. 详细报价明细

## 现状与问题

1. 项目目录为空，所有资料需从零编制
2. 知令企业版目前为产品设想，需要明确企业特性范围
3. 团队计算集群经验无现成文档，需根据实际项目经历整理
4. 大模型本地部署方案需结合当前主流硬件和开源模型进行调研

## 关键点和风险提示

1. **知令企业版特性**：目前知令是C端产品，企业版需要假设性设计多用户管理、权限控制、审计日志等功能
2. **大模型硬件方案**：需要给出合理的硬件配置建议（GPU服务器、存储等），既要满足性能需求，又要与200万+预算匹配
3. **团队经验可信度**：高校计算集群经验需要具体可查证的描述，避免空泛
4. **报价合理性**：200万+预算需要详细的费用拆分（硬件、软件、服务、培训、运维）
