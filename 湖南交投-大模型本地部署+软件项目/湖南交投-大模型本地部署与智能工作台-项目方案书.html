01公司及团队介绍

1.1 公司介绍

西安禾成讴沃信息科技有限公司（以下简称"公司"）成立于陕西省西安市，是一家专注于人工智能应用与智能工作平台研发的科技企业，系"知令（ZHILING）"品牌持有者。公司以"让智能触手可及"为核心理念，致力于打造桌面与移动全场景智能工作平台，让 AI 智能体真正服务于科研、工程与日常办公的每一个环节。

公司自主研发的核心产品知令（ZHILING）是一款面向科研与工程场景的全流程智能工作台，支持 Windows、macOS、Linux 桌面端与 Android、iOS 移动端多端无缝协同。产品深度整合 DeepSeek、GLM、Kimi、MiMo 等国产大模型，通过 Prompt 工程、工具链编排与上下文管理等全链路优化，为用户提供多模型会话、复杂任务规划、自动化任务编排、文档协作、远程集群计算对接等核心能力，覆盖代码开发、文档精修、数据分析、科学计算、演示制作等全链路工作流。

在技术方向上，公司深耕 AI 智能体、大模型应用、高性能计算与自动化任务编排四大领域，具备从大模型本地化部署与推理优化，到计算集群建设、多端应用开发的完整技术能力。公司自主研发了多端三层按需同步协议、自动化任务引擎（支持定时与条件触发、计划书驱动的全流程自动编排）、本地优先的安全架构等关键技术，敏感数据可完全保留在用户环境内部，充分满足企业对数据安全与合规管理的要求。

目前，公司产品与服务已应用于高校实验室、企业研发中心与科研工作者群体。面向企业级市场，公司将持续深化大模型应用与智能工作平台的研发，助力大型企业客户实现办公与业务的智能化转型。

02技术方案

2.1 项目概述

1）项目背景

湖南交投集团作为湖南省属大型国有企业，在高速公路投资建设、运营管理、交通基础设施建设等领域拥有庞大的业务体系和海量的工程文档、合同文件、规章制度、技术规范等信息资产。传统办公模式下文档检索效率低、信息分散、知识沉淀困难等问题日益凸显，亟需引入人工智能技术提升办公智能化水平。

大语言模型（LLM）技术的快速发展为企业知识管理与智能办公带来了变革性机遇。通过将大模型本地化部署至集团内部数据中心，结合企业知识库构建智能工作平台，可在保障数据安全的前提下大幅提升工作效率与管理决策水平。

2）建设目标

  1. 构建安全可控的大模型算力平台：在集团数据中心部署 GPU 推理服务器集群，实现开源大模型的本地化私有部署，数据不出企业内网，满足《数据安全法》及等保三级合规要求。
  2. 搭建企业级智能工作台：基于知令（ZHILING）产品定制企业版智能工作台，集成统一认证、权限管理、审计追踪、品牌定制等企业级特性。
  3. 建设企业知识库与 RAG 问答体系：将集团非结构化数据转化为可检索、可问答的企业知识资产，实现"即问即答"的智能知识服务。
  4. 赋能核心业务场景：围绕智能公文撰写与审核、工程文档智能检索、项目资料智能整理、内部制度问答、代码辅助开发与安全审查等典型场景，实现 AI 与业务深度融合。

3）方案总体思路

本方案遵循"算力平台 → 模型服务 → 智能工作台 → 业务应用"四层架构，以开源大模型为核心引擎，以知令企业版为应用载体，以企业知识库为数据基座。技术选型采用"主流 NVIDIA GPU 为主、信创华为昇腾为辅"的双轨策略；模型选型采用"通用对话 + 深度推理 + 代码辅助 + 嵌入检索"的多模型矩阵；部署运维遵循"分阶段实施、先试点后推广"的项目推进策略。

2.3.3 推理框架与部署架构

推理引擎选型：vLLM

生产环境选用 vLLM 作为推理引擎，核心优势包括：

  • PagedAttention 显存管理：将 KV Cache 分页管理，显存利用率提升 2—4 倍，相同硬件可承载更大吞吐；
  • 连续批处理（Continuous Batching）：动态合并请求，吞吐量达传统静态批处理的 10 倍以上；
  • 张量并行（Tensor Parallelism）：将大模型切分到多张 GPU 并行推理（如 Qwen2.5-72B 分 4 卡），支持 NVLink 高速互联；
  • 量化支持：原生支持 AWQ、GPTQ、INT8 等多种量化格式，在保持推理质量的前提下大幅降低显存占用；
  • OpenAI 兼容 API：提供与 OpenAI Chat Completions 完全兼容的 REST API，无缝对接知令客户端。

部署架构：

  • H20 服务器部署 vLLM 主实例（Qwen2.5-72B + DeepSeek-R1 蒸馏版），采用张量并行跨 4 卡推理；
  • L40S 服务器部署 vLLM 辅助实例（Qwen2.5-Coder-32B + Qwen2-VL-7B + BGE-M3），独立 GPU 分配；
  • 昇腾服务器（可选）部署 vLLM-Ascend 适配版（Qwen3-32B 昇腾版），CANN 异构计算架构；
  • 所有推理实例通过 API 网关（Nginx/Kong/APISIX）统一对外暴露，实现鉴权、限流、路由与负载均衡。

2.3.4 RAG 知识库方案

RAG（检索增强生成）管线是实现企业知识库智能问答的核心技术链路：

阶段技术组件说明
文档解析Unstructured / LlamaParse + Qwen2-VL OCR支持 PDF/DOCX/XLSX/PPTX/TXT/Markdown 等多格式解析；含扫描件 OCR 识别与表格提取
智能分块语义分块（Semantic Chunking）基于文档结构与语义边界自动切分，每块约 512 token，上下文窗口 ±2 块，保留段落完整性
向量嵌入BGE-M3 嵌入模型1024 维向量，支持中英双语，稠密+稀疏混合检索；日处理千万级文档块
向量存储Milvus 分布式集群存算分离架构（etcd + MinIO），支持 IVF_FLAT / HNSW 索引，10 亿级向量规模，检索延迟 < 100 ms
重排序BGE-Reranker-v2-m3对初步检索结果（Top 20—50）进行精排，显著提升召回精度
上下文组装Prompt 模板引擎将检索结果 + 用户问题 + 系统指令组装为完整 Prompt，注入 LLM 生成
流式输出SSE（Server-Sent Events）支持流式输出含引用来源的答案，用户可追溯每条回答的知识来源
知识库容量规划：支持 2000 万—5000 万文档块（每块约 512 token），总向量数据约 100—250 GB。支持按部门/角色设置知识库访问权限，实现数据隔离。

Token 配额管理按用户/部门分配 Token 使用额度，支持超额预警与自动限流
运维监控面板GPU 利用率/显存/温度实时监控、模型推理 QPS/延迟趋势图、用户活跃度（DAU/MAU）、系统告警

客户端集中分发Windows 安装包（支持静默安装 + 组策略分发），macOS DMG，麒麟 V10 AppImage

2.4.3 典型应用场景

📝 智能公文撰写与审核辅助

集团办公室每日需撰写大量通知、报告、会议纪要等公文。用户输入简要指令（如"拟一则关于安全生产检查的通知"），大模型自动生成符合《党政机关公文格式》GB/T 9704 规范的完整初稿；支持公文智能润色（去口语化、规范用词）、多版本对比、法规引用校验。

🔍 工程文档智能检索与问答

用自然语言提问（如"某高速 K12+300 段桥梁桩基设计参数"），系统从数千份工程文档中精准检索相关内容并生成摘要回答。支持跨文档关联分析（设计方案 ↔ 施工记录 ↔ 监理报告），AI 经过交通行业语料适配，能准确理解"压实度""弯沉值""CBR"等工程专业术语。

📊 项目资料智能整理与分析

上传项目散落的文档（会议记录、工作日志、影像资料等），AI 自动识别文档类型并按项目/时间/类别归档；输入多份项目文件，AI 自动提炼关键信息生成结构化的项目周报/月报摘要；从合同、报表中提取关键数据，自动生成统计表格与趋势图表。

📋 内部规章制度问答

将所有内部规章制度导入 RAG 知识库，员工用自然语言提问（如"带薪年假怎么申请？""差旅费报销标准是多少？"），AI 即时给出准确回答并标注制度来源；支持制度冲突检测与新员工指引。

💻 代码辅助开发与安全审查

集团信息中心开发人员在知令中描述需求，Qwen2.5-Coder-32B 自动生成符合规范的代码片段；提交代码至 AI 进行安全审查，检测 SQL 注入、XSS、硬编码密码等安全漏洞；支持根据代码自动生成 API 文档与技术文档、Bug 定位辅助。
