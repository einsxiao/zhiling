## 1. 公司及团队介绍

### 1.1 公司介绍

西安禾成讴沃信息科技有限公司是"**知令（ZHILING）**"品牌持有者，专注于 AI 应用与智能工作平台研发。核心产品知令是一款全流程智能工作台，支持 Windows/macOS/Linux 桌面端与 Android/iOS 移动端多端协同，深度整合 DeepSeek、GLM、Qwen 等国产大模型，覆盖代码开发、文档精修、数据分析、科学计算等全链路工作流。

公司深耕 **AI 智能体、大模型应用、高性能计算与自动化任务编排**四大领域，具备从大模型本地化部署与推理优化，到计算集群建设、多端应用开发的完整技术能力。

### 1.2 团队介绍

- **大模型应用与部署**：长期从事 DeepSeek、GLM、Qwen 等国产大模型本地化部署，具备推理加速、显存优化、服务化封装等工程经验。
- **高性能计算集群建设**：曾为多所高校建设 20+ 节点 SLURM 集群、GPU 计算集群、CPU+GPU 混合架构平台。
- **全栈软件研发**：Electron + React（桌面端）、React Native（移动端）、Django（服务端）、Go（高性能组件）。
- **AI 智能体研发**：自主研发多模型调度、工具链编排、Prompt 工程与上下文管理等核心技术。

## 2. 技术方案

### 2.1 项目概述

#### 背景

湖南交投集团拥有海量工程文档、合同文件、规章制度等信息资产，传统办公模式下文档检索效率低、信息分散、知识沉淀困难。通过大模型本地部署 + 企业知识库 + 智能工作台，可在保障数据安全的前提下提升办公智能化水平。

#### 建设目标

1. 构建安全可控的大模型算力平台（数据不出企业内网，等保三级）
2. 搭建企业级智能工作台（知令企业版，统一认证/权限/审计）
3. 建设企业知识库与 RAG 问答体系
4. 赋能智能公文撰写、工程文档检索、项目资料整理、制度问答、代码辅助五大场景

#### 方案思路

**"算力平台 → 模型服务 → 智能工作台 → 业务应用"四层架构**；"主流 NVIDIA GPU 为主、信创华为昇腾为辅"双轨策略；"通用对话 + 深度推理 + 代码辅助 + 嵌入检索"多模型矩阵；"分阶段实施、先试点后推广"推进策略。

### 2.2 总体架构

### 2.3 大模型算力平台方案

#### 2.3.1 硬件配置清单

| 设备 | 数量 | 核心配置 | 用途 |
|------|:--:|------|------|
| GPU 推理服务器（主） | 1 台 | 4×NVIDIA H20（96 GB HBM3），1 TB 内存 | Qwen2.5-72B + DeepSeek-R1 蒸馏版 |
| GPU 推理/管理节点（辅） | 1 台 | 2×NVIDIA L40S（48 GB GDDR6），512 GB 内存 | 代码辅助 + 文档 OCR + 嵌入服务 |
| 信创试点服务器（可选） | 1 台 | 2×华为昇腾 910B（40 GB HBM2e） | 信创路线试点 |
| 存储服务器 | 1 台 | 4×3.84 TB NVMe + 4×12 TB HDD | 模型/向量/文档/日志存储 |
| 网络交换机 | 1 台 | 100 GbE / 25 GbE | 高速推理网络 |
| 机柜/配电/散热 | 1 套 | 双机柜，液冷+强风冷，PUE ≤ 1.2 | 供电散热保障 |

#### 2.3.2 模型选型与部署

| 服务场景 | 模型 | 参数量 | 精度 | GPU 分配 |
|----------|------|--------|------|----------|
| **通用对话** | Qwen2.5-72B-Instruct | 72B | INT8 | 4×H20 |
| **深度推理** | DeepSeek-R1-Distill-Qwen-32B/70B | 32B/70B | INT8 | 2—4×H20 |
| **代码辅助** | Qwen2.5-Coder-32B-Instruct | 32B | BF16 | 2×L40S |
| **文档 OCR** | Qwen2-VL-7B-Instruct | 7B | FP16 | 1×L40S |
| **文档嵌入** | BGE-M3 | 568M | FP16 | 1×L40S 共享 |

> 所有模型均为开源模型（Apache 2.0 / MIT），不产生额外许可费用。

#### 2.3.3 推理框架

选用 **vLLM**（高性能推理引擎）：
- **PagedAttention**：显存利用率提升 2—4 倍
- **连续批处理**：吞吐量达传统方式 10 倍以上
- **张量并行**：多 GPU 协同推理，支持 NVLink 高速互联
- **量化支持**：AWQ/GPTQ/INT8，大幅降低显存占用
- **OpenAI 兼容 API**：无缝对接知令客户端

部署架构：H20 主实例 + L40S 辅助实例 + 昇腾试点，通过 API 网关（Nginx/Kong/APISIX）统一对外服务。

#### 2.3.4 RAG 知识库方案

| 阶段 | 技术组件 | 说明 |
|------|----------|------|
| 文档解析 | Unstructured + Qwen2-VL OCR | 支持 PDF/DOCX/XLSX/PPTX，含扫描件 OCR |
| 智能分块 | 语义分块 | 每块约 512 token，保留段落完整性 |
| 向量嵌入 | BGE-M3 | 1024 维，中英双语，稠密+稀疏混合检索 |
| 向量存储 | Milvus 分布式集群 | 10 亿级向量规模，检索延迟 < 100 ms |
| 重排序 | BGE-Reranker-v2-m3 | Top 20—50 精排，提升召回精度 |
| 输出 | SSE 流式 + 引用来源 | 答案可追溯到知识来源 |

> 知识库容量规划：2000 万—5000 万文档块，约 100—250 GB 向量数据。

### 2.4 知令企业版智能工作台方案

#### 2.4.1 现有产品能力

- **多模型会话**：同时接入多个大模型，自由切换对比
- **流式推理**：SSE 流式输出，Token 逐字生成
- **工具调用**：AI 按需调用代码执行、文件操作、网络搜索等本地工具
- **文件管理**：支持 Markdown/DOCX/PPTX/XLSX/PDF 多格式编辑与转换
- **任务编排**：自动化任务引擎（定时 + 条件触发）、计划书驱动编排
- **多端协同**：桌面端 + 移动端，数据实时同步
- **本地安全**：敏感数据默认保留本地，支持离线使用

#### 2.4.2 企业版增强特性

| 特性 | 说明 |
|------|------|
| 统一认证与 SSO | AD/LDAP 对接，多因素认证（密码 + 短信/OTP） |
| RBAC 权限管理 | 管理员/部门负责人/普通用户多级角色 |
| 会话数据隔离 | 不同用户/部门对话完全隔离 |
| 全量审计日志 | 登录/模型调用/文件操作全量记录，支持检索导出 |
| Token 配额管理 | 按用户/部门分配额度，超额预警与限流 |
| 运维监控面板 | GPU 监控、推理 QPS/延迟趋势、用户活跃度、系统告警 |
| 品牌定制 | LOGO/主题色/登录页/启动画面定制为交投集团 VI |
| 客户端分发 | Windows 安装包（静默安装 + 组策略）/ macOS DMG / 麒麟 AppImage |

#### 2.4.3 典型应用场景

1. **智能公文撰写与审核**：自动生成符合 GB/T 9704 规范的公文初稿，支持润色、校对、法规引用校验。
2. **工程文档智能检索**：自然语言检索数千份工程文档，支持跨文档关联分析与专业术语理解。
3. **项目资料智能整理**：自动归档、摘要生成、数据提取与统计报表。
4. **内部制度问答**：RAG 知识库覆盖全部规章制度，即问即答，标注来源。
5. **代码辅助与安全审查**：代码生成、安全漏洞检测、API 文档自动生成、Bug 定位。

## 3. 实施计划

### 3.1 实施总体策略

| 策略 | 说明 |
|------|------|
| **分阶段交付** | 五个阶段递进式交付，每阶段设明确里程碑与交付物 |
| **硬件先行，软件跟进** | 第 1 月启动采购，软件云端并行开发，硬件就绪即部署 |
| **先试点后推广** | 试点部门运行 2—3 周，反馈优化后全集团推广 |

### 3.2 项目阶段划分（总工期约 6 个月）

| 阶段 | 时间 | 核心工作 |
