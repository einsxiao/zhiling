# 知令（ZHILING）

> 🚀 一站式科研与工程协作平台 — 用自然语言驱动 AI，让计算触手可及

**知令**是一款桌面端全流程工作平台，专为科研人员与工程师打造。它将 **AI 智能体**、**代码与文档编辑**、**计算任务管理**和**远程集群对接**无缝融为一体——你可以用自然语言与 AI 对话，完成从文献阅读、论文撰写、代码开发到作业提交的全链路工作，告别在多个工具间来回切换的低效模式。

## ✨ 为什么选择知令？

| 痛点 | 知令的解决方案 |
|------|---------------|

## 🎯 核心功能

### 🧠 AI 智能体 — 你的全能科研助手

- **多模型支持**：DeepSeek、Kimi、Doubao、Mimo 等主流大模型随心切换，也支持 BYOK 接入自有 API
- **自然语言驱动**：直接对话即可让 AI 读取文献、修改论文、编写代码、提交计算任务
- **流式推理**：实时查看 AI 的思考过程，复杂推理透明可见
- **多种工作模式**：通用 Agent / 只读问答 / 计划模式 / 科研写作 / 调试模式，按需选择
- **技能包**：可扩展的 AI 能力库，按场景加载专业工具

### 📝 文档与代码编辑 — 一应俱全

- **代码编辑器**：类 VS Code 体验，语法高亮、小地图、Vim 模式、多语言支持
- **Markdown**：实时预览，支持 Mermaid 流程图、LaTeX 数学公式、D3/ECharts 可视化
- **Word 文档**：原生 DOCX 查看与编辑，AI 辅助润色与格式调整
- **PDF 阅读**：内嵌阅读器，AI 可将 PDF 自动转为高质量结构化文本供分析
- **代码智能**：AI 可跨文件理解项目上下文，精准定位与修改

### ⚡ 计算任务管理 — 从本地到超算

- **统一任务文件（.task）**：一套语法描述计算作业，同时支持 SLURM 集群调度和本地 Shell 执行
- **实时状态跟踪**：提交后自动轮询状态（排队 → 运行 → 完成/失败），无需手动刷新
- **远程日志查看**：直接在界面中查看集群输出日志，支持 Plotly 数据可视化
- **AI 驱动提交**：在对话中说"帮我把这个任务提交到集群"，AI 自动完成

### 🔗 远程项目管理 — 像本地一样操作远程

- **SSH 文件管理**：远程服务器的文件树、编辑、搜索与本地操作体验一致
- **远程终端**：内置 SSH 终端，支持多标签，无需额外终端软件
- **安全连接**：支持密码和密钥认证，连接池管理保证稳定性

### 📊 数据与可视化

- **数据库连接**：PostgreSQL、MongoDB 直连查询，AI 辅助写 SQL
- **知识库管理**：浏览与管理项目相关知识文档
- **丰富图表**：Plotly、Mermaid、D3、ECharts 多种可视化引擎内嵌

### 📧 邮箱集成

- **多账户绑定**：IMAP/SMTP 统一收件箱
- **AI 邮件助手**：智能体可代你收发邮件、处理审稿通知等

### ⏰ 自动化

- **定时任务**：按时间计划自动执行 AI 工作流
- **事件触发**：邮件到达等事件自动触发处理流程

### 🎨 个性化定制

- **深浅主题**：自动适配系统主题，护眼舒适
- **布局灵活**：智能体面板自由切换左右位置
- **自定义模式**：创建专属 AI 工作模式，定义工具策略
