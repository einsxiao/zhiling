# 知令产品介绍 · 竖版海报 —— 使用说明

本目录是「知令产品介绍」竖屏电子版 + A3 打印版海报的交付物。
海报为**单文件自包含 HTML**（内联 CSS / 内联 SVG：应用图标、「知令」字标、8 枚能力图标、行动区官网二维码，不引用任何外部文件或网络资源），
可同时用于 **1080×1920** 电子屏传播与 **A3（297×420mm）竖版打印**。

视觉语言复用「知令合伙人计划·校园海报 v5 定稿」的全浅色高级极简风（白底 + 超大字号 + 大色块 + 大留白）。
自上而下**六段结构**：

**A 品牌行**（知令应用图标 + 「知令」字标，字标着色统一到页面主色 `--blue`）
→ **B 主视觉**（眉标「知令 · 开箱即用的全场景智能工作台」+ 左侧品牌蓝渐变竖条 + 192rem 双色超大标题「干活」+ 一行导语）
→ **C 数字带**（浅蓝底双大数字带：**1M** 上下文 / **¥10** 新体验金 + 底部口径脚注）
→ **D 八大能力**（kicker「八大能力」+ 2 列 × 4 行卡片网格，每卡＝图标 + 标题 + 一句描述）
→ **E 行动区**（**左右等分对称**：`grid-template-columns:1fr 1fr`，左＝网址锁排 `https://` + `zhiling.plus` + 渐变短线，右＝官网二维码卡片（内联 SVG 码面 220rem + 四角蓝标）；左侧网址置于与二维码卡**等高的 254rem 定高框内垂直居中**，两侧说明行共用同一字号/字重/颜色且**上下沿严格对齐**；画布正中一条 2rem 淡渐变竖线作镜像对称轴）
→ **F 页脚**（贴底靠右：两行产品口径小字 + 落款「知令 · 让 AI 干活，让 Token 自由」）。

**与母本的关键差异**：中后段由校园海报的「三步加入 + 合伙人二维码」替换为「八大能力网格 + 产品行动区」；
产品行动区＝**网址锁排 + 官网二维码（内联 SVG）**，二维码**仅呈现官网 `https://zhiling.plus`**，不含任何合伙人 / 收益 / 邀请 / 邀请码类内容。

   | 眉标「知令 · 开箱即用的全场景智能工作台」 | `.eyebrow` | 前面 44×5rem 蓝色短线由 `.eyebrow::before` 生成 |

   | 主标题第 2 字「活」 | `.title .t2` | 192rem 品牌蓝渐变字，见下方「渐变字写法」 |

3. **单点换色**：整页强调色由 `:root` 的 `--blue:#545BFC` / `--blue2:#7C6FF7` / `--grad` 三个令牌驱动
   （字标、眉标、数字、图标、网址前缀、落款间隔点等均取用），**改 `--blue` 一处即可整体联动**；但注意
   **应用图标 `#3780ff` 与应用内联 `fill` 为官方固有色，换色时不要动**。
4. **渐变字写法**（`.title .t2`，照搬母本，避免字形溢出被裁）：
   ```css
   .title .t2{background:var(--grad);-webkit-background-clip:text;background-clip:text;
     -webkit-text-fill-color:transparent;color:transparent;padding:28rem 0;margin:-28rem 0;}
   ```
   `padding` 与等量负 `margin` 用于扩大渐变背景盒覆盖字形溢出，且不改变排版高度。
5. **中文断词约定**：所有正文短句统一 `word-break:keep-all;overflow-wrap:break-word;`（`.card .cd`、`.lead`、
   `.band .desc`、`.band .foot`、`.footer p`、`.action .note` 均已设置），避免出现「半个词」的换行；
   改文案后建议按第五节复查断词（尤其卡片描述）。
6. 改完文案后**重新导出**（见第四节）。

## 四、如何重新导出

前置：Windows + Google Chrome（默认 `C:\Program Files\Google\Chrome\Application\chrome.exe`）。

```powershell
pwsh -File "D:\work\zhilingdoc\知令产品介绍-海报\_scripts\export_poster.ps1"
```

脚本依次导出 **1x PNG → 2x PNG → A3 PDF** 并写回本目录。关键点（脚本已内置）：

- **中文路径规避**：Chrome 命令行在含中文的路径上偶发静默失败，脚本先把 HTML 复制到 `%TEMP%` 下的
  ASCII 临时目录渲染，再把产物拷回交付目录（文件名仍为中文）。
- **独立档案目录**：每次导出使用独立 `--user-data-dir=<临时目录>`，否则命令行会被转发到正在运行的 Chrome 实例导致不产出文件。
- **透明底**：截图加 `--default-background-color=00000000`（必须为十六进制/RGBA 形式）。
- 2x 用 `--force-device-scale-factor=2`；窗口统一 `--window-size=1080,1920`；
  PDF 用 `--no-pdf-header-footer --print-to-pdf=...`。

> A3 上 9:16 内容按高度贴合、**左右自动留白居中**（与母本一致，属预期，不视为版式缺陷；只核对为单页 297×420mm）。

## 五、如何自检

改完文案/换色/重导出后，建议按下面五步实测（脚本均在 `_draft/`）：

1. **版式量测（零溢出/留白）**
   ```powershell
   node "D:\work\zhilingdoc\知令产品介绍-海报\_draft\measure.mjs" "D:\work\zhilingdoc\知令产品介绍-海报\知令产品介绍-海报.html"
   ```
   判据：`overflow ≤ 0`（纵向零溢出）、`bodyScrollW = docScrollW = 1080`（横向零溢出）、
   `actionToFooter = 22`（因页脚贴底，该值＝行动区底部到页脚线的剩余留白；≥20 视为正常）、`eyebrowLines == 1`、`titleFont == 192`。

## 六、设计约定与禁止项

- **单文件自包含**：CSS / SVG 全部内联，`src=` / `href=` 外部引用数为 **0**（仅允许 `data:` / `#`）；
  除行动区显示用的 `https://` 文本外，正文不含 `http(s)://` 链接；不使用 `<img>`、外链样式表或外链脚本。
- **二维码白名单**：行动区允许且**仅允许**呈现**官网二维码**（内容严格为 `https://zhiling.plus`，内联 SVG），与网址锁排（`https://` 小字 + 主域名大字 + 渐变短线）左右并排；**不得**出现邀请码 / 社交码 / 群二维码 / 合伙人相关二维码。
- **不出现合伙人/收益类字样**：禁用「Token 券 / 合伙人 / 分红 / 返佣 / 提现 / 收益 / 邀请 / 18 周岁 /
  Hermes / Nous Research / OpenClaw / 保本 / 稳赚 / 投资回报 / 年化」等；福利口径**只保留「注册即得 ¥10 体验金」**。
- **不提外部产品名**：科研能力按「学术搜索 / 论文解读 / 文献综述与写作」的场景口径写，不出现第三方产品名。
- **只做浅色打印版**：本物料为打印/投屏导向的浅色海报（白底），不产出深色变体（非 App 组件，不适用深浅色适配约定）。
- **不改动主项目**：`D:/work/zhiling` 与既有校园海报目录一律**只读**；新物料只落在本目录。
